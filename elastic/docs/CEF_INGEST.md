# CEF ingest path (NATCA 22.1)

NATCA requires logs generated by the System under Consideration to follow **Common Event Format (CEF)** with ISO 8601 timestamps.

## Demo approach

1. **Direct index (default):** `simulator.py` writes a normalized CEF document to `logs-cef.log-simulated`, including `event.original` with the raw CEF line. This is enough for the demo narrative without running Agent.

2. **Elastic Agent concentrator (optional):**
   ```bash
   mkdir -p simulator/cef_out
   echo 'CEF:0|MTA-Sim|IDMZ-FW|1.0|400|Modbus Write Denied|8|src=10.10.50.12 dst=10.40.2.15 proto=TCP' \
     >> simulator/cef_out/idmz.cef.log
   docker compose --profile agent up -d elastic-agent
   ```
   Agent config: [`agent/elastic-agent.yml`](../../agent/elastic-agent.yml).

## Talking points

- CEF at the IDMZ boundary; Elastic normalizes to ECS.
- Tamper protection / multi-region copies: call out Elastic Cloud snapshot + cross-cluster replication as the platform answer (not implemented in this demo).
